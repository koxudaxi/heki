## What it does
Checks quadratic accumulation of immutable values in a loop:

- `acc = acc + chunk` / `acc += chunk` where `acc` is a `bytes` or `tuple`;
- `self.text += piece` on an attribute that the class's methods in the module (or, for another
  receiver, the function) only ever assign a string, bytes, or tuple literal of the pieces'
  kind (`self.text = ""`): `self.values += (i,)` extends a list in place.

Local `str` accumulation is not reported: CPython already appends in place when the string has
no other reference. Neither are:

- an accumulator the loop's own test caps at a small constant (`while len(buf) < 10`, also
  as one `and` operand or with a module constant: at most 4096), whatever the input;
- `obj.attr += x` where `obj` is a different object in every iteration (the loop element, or
  an object created in the iteration): each attribute gets one piece.

## What a report states

A report states that an immutable value (`bytes`, a `tuple`, a `str` attribute) grows by
concatenation on every iteration of the loop, so each iteration copies all of it.

Its premises:

- **Immutable type**: the value's exact type is known from its construction. Established.
- **Loop-carried**: the result is the value of the next iteration. Established by the IR.
- **On every iteration**: the statement runs on every iteration of the loop. Open: a statement under
  a branch inside the loop counts.
- **Data-sized**: the code does not fix the sizes the cost depends on (the loop's and the
  container's) at 16 or fewer. Open: a size heki cannot bound counts as data-sized.
- **Rewrite proven safe**: the help says `[safe fix: ...]`, `[proven-safe suggestion: ...]`, or
  `[proven safe; ...]`. A report whose help names a blocking obligation instead (`[not auto-fixable:
  ...]`) lacks this premise and is heuristic whatever the rule's certainty; the proven reports are
  the rule's exact tier.

## Why is this bad?
Each concatenation copies everything accumulated so far.

## Example
```python
def encode(parts: list[bytes]) -> bytes:
    out = b""
    for p in parts:
        out = out + p
    return out
```

Use instead:
```python
def encode(parts: list[bytes]) -> bytes:
    return b"".join(parts)
```

## Fix safety
No automatic fix (the rewrite needs a buffer before the loop and a join after it). The
diagnostic still lists the proof obligations: the accumulator must not be read inside the loop
or by an exception handler, and its intermediate values must not escape.
