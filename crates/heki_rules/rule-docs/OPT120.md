## What it does
Checks loops that remove the first element of a list: `q.pop(0)`, `del q[0]`, and
`q = q[1:]`, and suggests a `collections.deque` with `popleft()`.

Size-dependent: applied only with `--fix --include-size-dependent` or in profiled hot
functions. The rewrite changes the list's creation to `collections.deque(...)` and adds
`import collections` when needed.

## Why is this bad?
Removing the first element shifts every remaining element, so a queue drained this way is
quadratic. `deque.popleft()` is constant time.

## Example
```python
def bfs(start: int) -> list[int]:
    queue = [start]
    order = []
    while queue:
        node = queue.pop(0)
        order.append(node)
    return order
```

Use instead:
```python
import collections


def bfs(start: int) -> list[int]:
    queue = collections.deque([start])
    order = []
    while queue:
        node = queue.popleft()
        order.append(node)
    return order
```

## Fix safety
Proven safe only when the list is created in the function, never leaves it (not returned,
stored, or passed to other code except read-only builtins such as `len`), and every use has a
`deque` equivalent: no sorting, no slicing, no indexes other than `0` and `-1`, no `==`
against lists.
