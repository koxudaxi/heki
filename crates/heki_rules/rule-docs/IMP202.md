## What it does
The strict mode of a `[[tool.heki.import-owners]]` contract that sets `unresolved = "report"`:
reports the imports of the judged modules that `IMP201` cannot judge because heki cannot name
the module they load, when that module may be one the contract does not allow:

- a by-name import (`importlib.import_module`, `__import__`) of a name the code does not fix;
- a by-name import of a name built from a known start (`f"pkg.plugins.{name}"`), unless no
  forbidden pattern can match a module under it, or an allowed glob covers every one
  (`pkg.plugins.*`);
- a by-name import of one of several names, some breaking the contract and some not;
- `from a import c` where heki cannot tell whether `c` is the submodule `a.c`: a package outside
  the project, one whose `__init__.py` binds `c` before the submodule may be imported, one that
  binds `c` to an object of the submodule after importing it (`from .c import c`), which the
  import takes the submodule instead of while the package is still loading, or one that binds no
  `c` while the project has no module `a.c`, which Python then looks for outside the project's
  files (a compiled extension module). The package `a` loads either way, and `IMP201` judges it.

With `reach`, the sites of the modules a walk reaches are judged too, and reported at the import
of the importer that starts the chain to them.

## What a report states

A report states that the importer has an import whose module heki cannot name, that may be one
the contract forbids or does not allow.

## Why is this bad?
A contract that passes says nothing about the imports heki cannot follow. `IMP202` reports them
under their own code, so they can be counted, kept in a baseline, and reduced by writing the
module name out, without mixing them with the violations `IMP201` proves.

## Example
```toml
[[tool.heki.import-owners]]
name = "core-plugins"
importers = ["pkg.core.*"]
forbidden-imports = ["pkg.plugins.*"]
unresolved = "report"
```

```python
import importlib


def plugin(name: str) -> object:
    return importlib.import_module(f"pkg.plugins.{name}")  # IMP202
```

## Fix safety
No automatic fix.

## Options
- `[[tool.heki.import-owners]]`:
  - `unresolved`: `"ignore"` (default) or `"report"`.
  - the other keys: as for `IMP201`.
